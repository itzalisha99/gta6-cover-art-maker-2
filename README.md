Vice Story turns your photo and a caption into a three-chapter GTA 6-style cover: three layouts, four colour grades, three post sizes, per-panel crop and zoom, exact-size PNG export, fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Pick a photo (or the sample), choose a layout, grade and post size, edit the caption and chapter tags, drag each panel to frame it, and export the PNG.
